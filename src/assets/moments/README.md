# Moment photos

Drop a photo here named after the moment's `id` (from `src/data.js`). It's picked up
automatically — no code change needed. Supported: jpg, jpeg, png, webp, gif, avif.

| file name | moment |
|-----------|--------|
| `first-saw.jpg` | 5 Jul 2026 — First Time I Saw Her |
| `first-message.jpg` | 29 Jul 2026 — First Message |
| `first-call.jpg` | 6 Aug 2026 — First Call |
| `she-said-yes.jpg` | 16 Aug 2026 — She Said Yes / Families' Approval |
| `first-date.jpg` | 23 Aug 2026 — First Date (the hill selfie) |
| `proposal-day.jpg` | 25 Aug 2026 — Proposal Day |
| `first-love-you.jpg` | 25 Aug 2026 — First "Love You" (the birthday "26" pic) |
| `her-first-ily.jpg` | 27 Aug 2026 — First "I Love You" From Kaviya |

Any moment without a photo just shows its emoji.
