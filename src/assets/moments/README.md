# Moment photos

Drop a photo here named after the moment's `id` (see `src/data.js`):

| id | date | moment |
|----|------|--------|
| `first-saw` | 5 July 2026 | First Time I Saw Her |
| `first-message` | 29 July 2026 | First Message |
| `first-call` | 6 August 2026 | First Call |
| `she-said-yes` | 16 August 2026 | She Said Yes / Families' Approval |
| `first-date` | 23 August 2026 | First Date |
| `proposal-day` | 25 August 2026 | Proposal Day |
| `first-love-you` | 25 August 2026 | First "Love You" |
| `her-first-ily` | 27 August 2026 | First "I Love You" From Kaviya |

Also: `cover.jpg` → shown as a large photo in the page header.

Example: `first-date.jpg`, `first-call.png`, `her-first-ily.webp`, `cover.jpg`.
Supported: jpg, jpeg, png, webp, gif, avif. They're picked up automatically — no code change needed.
