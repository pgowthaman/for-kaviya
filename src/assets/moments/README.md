# Chapter photos

Drop a photo named after a chapter's `id` (from the `chapters` array in `src/data.js`).
It's picked up automatically — no code change. Supported: jpg, jpeg, png, webp, gif, avif.

Current:
- `home.jpg` — Page 1 (birthday couple photo)
- `first-date.jpg` — 23 Aug, "Our First Date" (the hill selfie)

Other chapter ids you can add photos for: `first-saw`, `first-message`, `first-call`,
`the-yes`, `night-changed`, `proposal`, `said-it-back`, `us`.
Chapters with no photo just render text.
